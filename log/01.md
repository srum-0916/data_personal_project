# 1차시: 주제 탐색

- 오늘 결정한 것:
  AI 관련 공개 데이터에서 탐구 주제를 찾고 Open LLM Leaderboard를 선택했다. 처음의 두 유형 점수 비교에서 회귀 예측으로 주제를 발전시켰다. 현재 분석 질문은 “선택한 네 유형의 공개 언어 모델에서, 모델 크기 30.809B 이하의 지시 수행 점수는 정말 모델 크기와 모델 유형만으로 예측할 수 있는가?”이다. 크기 범위 제한은 이후 통계 점검에서 결정한 사항이다.

- AI에게 보낸 프롬프트(원문):
  > AI와 관련된 데이터 셋을 가지고 [https://teacher188-netizen.github.io/datascience-2026/project.html ](https://teacher188-netizen.github.io/datascience-2026/project.html)여기 이 개별 프로젝트를 진행하려고 하는데 어떤 주제로 하면 좋을지 먼저 추천해줘

- AI가 준 것 중 고치거나 버린 것과 그 이유:
  단순한 유형별 점수 비교를 넘어 예측 모델과 기준선을 비교할 수 있도록 질문을 수정했다. 원본 Type에는 학습 방식뿐 아니라 병합 방식도 포함되어 있으므로 ‘학습 유형’ 대신 ‘모델 유형’이라는 표현을 사용한다.

- 느낀 점:
  주제 선정을 하면서 생각보다 주제를 찾는 일과 그에 맞는 데이터 셋을 찾는 과정이 쉽지 않았다는 것이었다. 그래서 반대로 여러가지 데이터 셋을 미리 찾고 거기서 나올 수 있는 주제를 선정하는 방식으로 프로젝트를 진행했다.
