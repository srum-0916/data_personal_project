# 2차시: 질문 다듬기·데이터 후보 찾기

- 오늘 결정한 것:
  처음에는 대화용·사전학습 모델의 점수를 비교했지만, 모델을 만들고 해석하는 탐구에 맞게 지시 수행 점수 예측으로 질문을 발전시켰다. 현재 질문은 “선택한 네 유형의 공개 언어 모델에서, 모델 크기 30.809B 이하의 지시 수행 점수는 정말 모델 크기와 모델 유형만으로 예측할 수 있는가?”이다. 입력은 모델 크기와 모델 유형, 예측 대상은 IFEval 점수이다. 평균 기준선·선형 회귀·랜덤 포레스트 회귀를 같은 분할에서 비교하고 MAE와 R²로 평가할 예정이다. 분야별 추가 학습·모델 병합 복원과 크기 범위 제한은 이후 검토 결과를 반영한 것이다.

- AI에게 보낸 프롬프트(원문):
  > 너는 회귀 모델이 제일 적합하는 거야? 어떤 모델을 만드는 게 가장 잘 어울리는 지 모르겠어
  > 그러면 데이터 가공했을 때 우리가 가공전, 대화형 특화 모델 두개만 남겼잖아. 이거 지운 다른 모델도 있어야 하는 거 아냐?

- AI가 준 것 중 고치거나 버린 것과 그 이유:
  기존 질문은 평균과 그래프만으로도 상당 부분 답할 수 있어 예측 질문으로 수정했다. 두 유형만 선택했던 범위도 재검토해 분야별 추가 학습과 모델 병합을 포함했다. 통계적 크기 제한을 적용했으므로 모든 크기의 AI에 대한 질문처럼 표현하지 않는다.

- 느낀 점:
  흥미로운 질문뿐 아니라 모델을 통해 무엇을 예측하고 알아볼 것인지도 명확해야 한다는 것을 배웠다. 질문을 수정하면서 분석 목적과 방법의 연결이 더 분명해졌다.
