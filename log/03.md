- 오늘 결정한 것:
  분석 범위는 Hugging Face Open LLM Leaderboard 데이터에 등록된 모델 중 ‘대화용’과 ‘사전학습’으로 분류된 모델이다. 지시 수행 능력은 답변의 형식·길이·키워드 등 명시된 조건을 지키는 정도를 평가하는 IFEval 점수로 비교한다.
  가공 데이터는 993행, 9열로 구성되어 있어 ‘행 50개, 열 6개 이상’ 조건을 충족한다. 실제 수치형 열도 모델 크기, 지시 수행 점수, 추론 점수, 수학 점수로 총 4개이므로 조건을 충족한다.
  우선 박스플롯으로 두 유형의 점수 분포를 비교하고, 유형별로 모델 크기와 지시 수행 점수 사이의 관계를 선형 회귀로 분석하기로 했다. 이후 예측 모델을 평가할 때는 학습 데이터와 테스트 데이터를 나누고 기준선과 성능을 비교할 예정이다.
  질문과 데이터가 과제 조건에 맞는지 확인했으며, 이를 바탕으로 선생님께 데이터 사용 승인을 요청하기로 했다.

- AI에게 보낸 프롬프트(원문):
  특히 지금 수치가 기록된 데이터들이 적어서 수치로 작성된 데이터로 만들어야 할 것 같아. 그리고 다른 데이터 정보들도 좀 더 간략화 해줘.

- AI가 준 것 중 고치거나 버린 것과 그 이유:
  대화용 여부와 대화 형식 사용 여부를 0과 1로 표시하는 방식은 읽기 어렵다고 생각해 텍스트로 바꿨다. 각각 ‘사전학습/대화용’, ‘미사용/사용’으로 표시해 뜻을 바로 알 수 있도록 했다.
  범주를 0과 1로 바꾸더라도 실제 양을 나타내는 수치형 변수가 되는 것은 아니므로, 수치형 열 조건은 모델 크기와 세 가지 평가 점수로 충족하도록 했다.
  또한 ‘지시를 더 잘 따른다’는 표현은 의미가 넓어, 실제 데이터에서 확인할 수 있는 ‘IFEval 점수가 높은가’로 질문을 구체화했다. 이 점수만으로 AI의 전체 능력이나 답변의 정확성을 판단하지 않도록 했다.

- 느낀 점:
  데이터는 행과 열의 개수만 많다고 적합한 것이 아니라, 내가 정한 질문에 답할 수 있는 정보가 있어야 한다는 것을 알게 되었다. 특히 범주를 숫자로 표시하는 것과 실제 수치가 기록된 변수는 다르다는 점을 배웠다. 앞으로 그래프에서 차이가 보이더라도 모델 크기나 구조 같은 다른 조건을 함께 살펴보고 해석해야겠다고 생각했다.
