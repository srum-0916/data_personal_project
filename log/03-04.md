# 3~4차시: 데이터 적합성 확인·기초통계 분석

- 오늘 결정한 것:
  원본 4,576행·36열의 기초통계를 확인하고, 원본 CSV를 불러오는 Streamlit 앱으로 결측치·평균·중앙값·표준편차와 분포를 살펴봤다. 유형별 원본 기록 수는 사전학습 275개, 대화용 718개, 분야별 추가 학습 1,785개, 모델 병합 1,724개이다. 이후 네 유형을 선택했다. 지속 사전학습 58개는 이번 범위에서 제외하고, 멀티모달 9개와 기타 7개도 제외했다. 기타는 양수 모델 크기를 가진 기록이 없었다. 최종 데이터는 후속 전처리 후 4,121행·9열이며 수치형 열은 크기와 세 점수로 4개다. 학습·테스트 성능 평가는 아직 진행하지 않았다.

- AI에게 보낸 프롬프트(원문):
  > 이게 원본인데 이걸 CSV로 바꿔줘
  > 어떤 모델을 추가로 복구시킬까? 기초통계자료를 기반으로 선택해줘.

- AI가 준 것 중 고치거나 버린 것과 그 이유:
  기존 두 유형만의 분석에서 네 유형으로 범위를 넓혔다. 지속 사전학습은 AI가 복원을 제안했지만 사용자가 이번 복원 대상에서 제외했다. 모델 크기만 사용한 낮은 R²는 예측 한계를 보여주는 탐색 결과로 남긴다. 현재 데이터에서 입력인 크기·유형과 예측 대상 점수의 결측치는 없고, 보조 변수인 모델 구조에는 6개 결측치가 남아 있다. 이 열을 나중에 입력으로 사용한다면 추가 처리가 필요하다.

- 느낀 점:
  기초통계와 분포를 확인하는 과정이 모델링에 앞서 필요하다는 것을 배웠다. 예측 성능이 낮아도 원인을 분석할 수 있으며, 같은 테스트 데이터에서 기준선과 모델의 성능을 비교하는 것이 중요하다고 느꼈다.
