범위를 30B로 지정한 이유가 뭐야?
정확히는 30B가 아니라 30.809B 이하야. 앞서 크기가 많이 튀는 기록을 정리할 때, 모델 크기의 분포를 기준으로 정한 상한이야.

계산은 이렇게 했어.

1사분위수(Q1): 6.061B
3사분위수(Q3): 12.248B
사분위범위(IQR): 12.248 − 6.061 = 6.187B
상한: Q3 + 3 × IQR = 30.809B
이 기준으로 4,394개 중 **273개, 약 6.2%**를 제외했어.

다만 30.809B를 넘는 모델이 잘못된 데이터라는 뜻은 아니야. 정상적인 대형 모델도 포함돼 있어서, 반드시 제거해야 했던 것은 아니고 우리가 분석 범위를 제한한 선택이야. 그래서 포스터에도 ‘이상한 데이터 제거’보다는 **“크기 분포의 통계적 기준에 따라 분석 범위를 30.809B 이하로 제한했다”**라고 설명하는 게 정확해. 그만큼 결론도 이 범위의 모델에 한정해야 하고!

범위를 정하지 않는다면 무슨 일이 일어나는데?
30.809B라는 크기 제한을 없애도 분석과 모델 학습은 가능해. 제외했던 대형 모델 273개가 돌아와 분석 대상이 4,121개에서 4,394개로 늘어나.

달라지는 점은 다음과 같아.

대형 모델까지 살펴볼 수 있어. 크기가 커졌을 때도 지시 수행 점수가 계속 높아지는지 확인할 수 있어.
학습한 관계와 예측 결과가 달라질 수 있어. 특히 선형 회귀는 크기가 매우 큰 모델들의 영향을 받아 회귀선의 기울기가 달라질 수 있어. 랜덤 포레스트도 대형 모델을 나누는 조건을 새로 학습하게 돼.
전체 평균만으로 판단하기 어려워질 수 있어. 대형 모델의 기록이 상대적으로 적으므로, 전체 MAE와 함께 크기 구간별 오차도 확인하는 게 좋아.
성능이 반드시 나빠지는 것은 아니야. 정상적인 데이터가 추가되는 것이므로 더 다양한 관계를 배울 수도 있어. 실제 영향은 계산해 봐야 알 수 있어.
솔직히 우리 질문이 ‘모델 크기와 유형으로 점수를 예측할 수 있는가?’라면, 유효한 대형 모델도 포함하는 편이 더 자연스러워. 크기가 크다는 이유만으로 제외할 필요는 없었어. 기존 처리는 분석 범위를 좁힌 선택이었고, 필수적인 오류 제거는 아니었던 거야.

제한의 영향을 확인하려면 같은 테스트 데이터를 고정해 두고, 대형 모델을 포함해 학습한 경우와 제외해 학습한 경우를 비교해야 해.

다시 학습해 봤어. 크기 제한을 없애도 전체 성능은 비슷했고, 대형 모델의 예측 오차는 줄었어.

응. 우리 연구 질문에는 크기 제한을 없애는 편이 더 적절하다는 근거가 있어. 개인의 해석뿐 아니라 분석 목적과 실제 비교 결과로 설명할 수 있어.

질문에 더 잘 맞아. 모델 크기와 점수의 관계를 알아보는데, 정상적인 대형 모델을 제외하면 살펴볼 수 있는 관계도 제한돼.

다만 전체 오차의 감소는 약 **1.9%**이므로, **“전체 성능이 크게 개선됐다”보다는 “분석 범위를 넓히면서 대형 모델의 예측 오차를 줄였다”**고 표현하는 게 정확해. 대형 모델 테스트가 43개라는 한계도 함께 적으면 되고.

첫째, 학습이 기록이 많은 유형에 더 맞춰질 수 있어.
